# Вітрина тортів

Односторінковий сайт для кондитерської з акцентом на класичні торти «Наполеон», «Дрова під снігом» та «П'яна вишня».

## Структура
- `index.html` — контент сторінки з блоками герою, карточками тортів, процесом роботи та CTA.
- `styles.css` — стилі з акцентними кольорами, шрифтами Google (Playfair Display та Inter) і адаптивною сіткою.

## Як переглянути
Відкрийте `index.html` у браузері. Додаткових залежностей або збірки не потрібно.
